# Claudio Skills — Herramientas globales + Portfolio de Gustavo

Repo central con dos cosas:

1. **`.claude/skills/`** — skills globales estandarizadas que se usan en todos los
   proyectos (TDD, debugging sistemático, brainstorming, UI/UX, verificación, etc.),
   incluida **`portfolio-tracker`**, el sistema de trazabilidad del portfolio.
2. **`portfolio/`** — la fuente de verdad del negocio: perfil, dashboard maestro,
   pipeline con deadlines, ficha por proyecto, métricas de sesiones/tokens e ideas.

## Uso rápido

- ¿Cómo van los proyectos? → leer `portfolio/PORTFOLIO.md`
- ¿Qué toca hacer ahora? → leer `portfolio/PIPELINE.md` (sprint activo)
- Empezar/terminar una sesión de trabajo → seguir `.claude/skills/portfolio-tracker/SKILL.md`
